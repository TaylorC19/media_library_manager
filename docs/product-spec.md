# Historical product specification

The original planning document described a retired Next.js/NestJS monorepo. Its environment examples, implementation prompts, and suggested portfolio wording are not instructions for the current Go application. The original planning material is retained privately for reference.

The product goals carried forward are a personal media Library, separate Collection and Wishlist views, server-side metadata lookup, explicit save actions, best-effort barcode matching, and separation of personal copy data from imported provider metadata.
